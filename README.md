# ColorblindExtension

## RUNNING INSTRUCTIONS
1. Go to code -> local -> download as ZIP
2. Go to your downloads folder, right click on the file, select "extract all"
3. Click on the extension icon in your browser -> manage extensions
4. In the top left, select "Load Unpacked"
5. Double click on the first folder and then select the folder inside the first
6. Select folder
7. The extension should be in!
